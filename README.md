# Keylogger Project

This project is a Node.js-based keylogger that securely logs keystrokes in an encrypted file (`keylog.enc`). It uses the `node-global-key-listener` library to capture global keypress events and encrypts the logged data using the AES-256-CBC algorithm.

## Features

- Logs keystrokes globally on the system.
- Encrypts the logged data to ensure secure storage.
- Includes a decryption script to retrieve logged keystrokes in a human-readable format.
- Tracks additional information such as timestamp and serial number for each keystroke.

## Prerequisites

- Node.js (v14 or above)
- npm (Node Package Manager)

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd <project-folder>
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```

## Usage

### Keylogger Script

To start logging keystrokes:

1. Run the keylogger script:
   ```bash
   node index.js
   ```
2. Press keys, and they will be logged to an encrypted file (`keylog.enc`) in the project directory.

### Decrypting the Log File

To decrypt the `keylog.enc` file and view the logged data:

1. Run the decryption script:
   ```bash
   node decrypt.js
   ```
2. The decrypted content will be saved to `decrypted.txt` in the project directory.

### Customizing the Encryption Key

By default, the project uses a hardcoded encryption key. To enhance security:

1. Replace the value of `ENCRYPTION_KEY` in `index.js` and `decrypt.js` with a secure key.
2. Ensure the same key is used in both files.

### Formatting the Timestamp

Keystroke logs include timestamps formatted as `DD/MM/YYYY, HH:MM:SS`. This can be adjusted in the `formatDateTime` function inside `index.js`.

## Project Structure

- `index.js`: Main keylogger script that captures and logs keystrokes.
- `decrypt.js`: Script to decrypt the encrypted log file (`keylog.enc`).
- `package.json`: Configuration file for dependencies and scripts.
- `keylog.enc`: Encrypted file where keystrokes are logged.
- `decrypted.txt`: Decrypted log file generated by `decrypt.js`.

## Troubleshooting

1. **Keylogger Not Capturing Keys:**

   - Ensure you have installed all dependencies using `npm install`.
   - Check if the `node-global-key-listener` library supports your operating system.

2. **Encryption Errors:**

   - Verify that the `ENCRYPTION_KEY` is exactly 32 characters long.

3. **Decryption Errors:**
   - Ensure the same `ENCRYPTION_KEY` is used in both `index.js` and `decrypt.js`.
